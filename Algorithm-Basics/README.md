# 🧮 Algorithm Basics & Logic

A collection of foundational programming projects demonstrating core algorithmic thinking, control flow, and computational logic. This section highlights the ability to translate mathematical and statistical concepts into efficient code.

## 📂 Projects Overview

* **[`Bean-Machine`](./Bean-Machine/)**: A statistical simulation of a Galton Board demonstrating the binomial distribution and Central Limit Theorem with optimized $O(1)$ memory allocation.
* **[`Fundamentals`](./Fundamentals/)**: Core programming exercises focusing on iterative logic, array manipulations, and standard control structures.
* **[`Recursion`](./Recursion/)**: Implementations of recursive algorithms to solve complex problems through self-referential function calls and base-case management.
